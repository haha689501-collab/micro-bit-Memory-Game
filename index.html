문제별 기록

🎮 마이크로비트 블록 변경

랜덤 값을 정하는 블록과 랜덤 조건문은 삭제해 주세요. 버튼마다 결과를 고정합니다.

이벤트넣을 블록
시작하면시리얼통신 연결 설정: USB
A 버튼 누를 때시리얼통신 전송: 한 줄 "O" → LED에 O 표시
B 버튼 누를 때시리얼통신 전송: 한 줄 "X" → LED에 X 표시

P0·P1 송신·수신 설정 블록은 사용하지 않습니다. USB 기본 속도는 115200입니다. 알파벳 O·X를 보내 주세요. 소문자 o·x도 받을 수 있습니다.

학생용 간단한 블록 구성

픽셀을 클릭하는 기본 ‘LED 출력’ 블록을 그대로 사용해도 됩니다. A 이벤트에는 한 줄 "O" 전송 → LED 출력(O 모양), B 이벤트에는 한 줄 "X" 전송 → LED 출력(X 모양) 순서로 넣으세요. 전송을 먼저 실행하지만 LED 출력에는 기본 0.4초 대기가 있으므로 빠른 연속 누름에는 영향이 있을 수 있습니다. 처음에는 이 간단한 방식으로 사용하고, 연속 입력이 불편할 때 아래 점 켜기 방식을 선택하세요.

빠른 연속 입력용 선택 구성

‘한 줄 전송’을 버튼 이벤트의 맨 위에 놓으세요. 기본 ‘LED 출력’ 블록에는 400ms 대기가 있어, 빠른 연속 누름에는 아래 LED 점 켜기 방식을 권장합니다. 웹은 O·X 문자가 도착하면 줄바꿈을 기다리지 않고 바로 처리합니다. 다른 디버그 문구는 전송하지 마세요. 같은 O를 연속으로 보내도 모두 입력합니다.

A 버튼: OB 버튼: X
① 한 줄 "O" 전송
② LED 스크린 지우기
③ i를 0부터 4까지 반복
반복 안에 LED 켜기:
x=0, y=i
x=4, y=i
x=i, y=0
x=i, y=4		① 한 줄 "X" 전송
② LED 스크린 지우기
③ i를 0부터 4까지 반복
반복 안에 LED 켜기:
x=i, y=i
x=4−i, y=i

블록 메뉴의 ‘반복’과 ‘LED’의 점 켜기 블록으로 구성합니다. 이 방식에서는 기존 큰 ‘LED 출력’ 블록을 빼 주세요. O는 사각 테두리 모양으로 표시됩니다. ‘잠시 멈춤’, ‘문자열 출력’, 추가 애니메이션은 버튼 이벤트에 넣지 않습니다.

게임 진행

  1. 바꾼 블록을 기기에 다운로드합니다.
  2. MakeCode 연결과 이전 게임 창을 닫습니다.
  3. 이 HTML에서 USB 연결 → 포트 선택 → 도전 시작.
  4. 순서를 보는 동안은 기다리고, ‘입력하세요!’가 나오면 A·B 버튼을 누릅니다.

끝까지 입력한 뒤 채점합니다. 중간에 다른 버튼을 눌러도 문제는 계속됩니다. 기록 대결은 10문제, 생존 도전은 목숨 3개로 시작합니다. 성공하면 완벽 정답 문제 수가 1개 늘어납니다. 실패하면 점수는 얻지 못하지만 다음 차례에는 다음 단계로 올라갑니다. 순위는 맞힌 기호 수 → 완벽 정답 문제 수 → 총 입력 시간(짧은 순)입니다. 입력 시간은 순서 표시·대기 시간을 제외하고 입력을 시작한 순간부터 측정합니다. 시간 초과는 해당 문제의 제한 시간을 기록합니다. 기록 대결과 생존 도전의 기록은 별도로 비교하세요.

USB 연결 실패 시 이전 HTML·MakeCode를 닫고 케이블을 다시 꽂아 주세요. 데이터 전송이 가능한 케이블과 컴퓨터 Chrome / Edge가 필요합니다. 미리보기 대신 다운로드한 파일을 직접 여세요.
